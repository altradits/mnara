# Security

## Report a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting on this repo. Go to the Security tab and choose "Report a vulnerability".

We will acknowledge within 72 hours. We will share a plan within 14 days. We will credit you unless you decline.

## Scope

In scope: header verification, peer handling, filter checks, the macaroon guard, the status page.

Out of scope: LND, Bitcoin Core, neutrino. Report those upstream. Attacks that need full control of the owner network path are a documented limit, not a bug.

## Supported versions

We support the latest minor release.
