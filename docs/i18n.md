# I18n

The UI speaks the owner language. About 40 strings in total. Small enough that one full translation is one sitting.

## System

- Catalogs live in `locales/<bcp47>.json`. Flat keys. `{placeholders}`.
- Plurals use CLDR plural objects via `golang.org/x/text/feature/plural`.
- Numbers format per locale via `x/text/message`.
- Page direction comes from the locale. CSS uses logical properties, so RTL works.
- Alert webhook bodies are machine JSON with codes and numbers. They need no translation.

## How to translate

1. Copy `locales/en.json` to `locales/<tag>.json`.
2. Translate every value. Keep keys, placeholders, and plural forms intact.
3. Keep the glossary words fixed per language: block, header, chain, peer, node, channel, sats.
4. Run the i18n check. Missing keys fall back to English and lower the score.

You must speak the language. Your own work only.

## Launch and targets

Launch: `en`, `sw`. Targets as translation issues: `fr`, `es`, `pt`, `de`, `ar`, `fa`, `zh-Hans`, `ja`, `hi`, `ru`, `tr`, `id`, `vi`, `ha`, `am`, `yo`, `luo`.

## Checks

`tools/i18ncheck` runs in CI. Unknown keys fail. Placeholder mismatches fail. Missing plural forms fail. Missing keys fall back to English and report a percent.
